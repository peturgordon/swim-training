## Warmup — 400m
- 200m easy free, relaxed
- 4×50 easy free/back alternating, 10s rest

## Technique — 400m
*(fresh, one cue only — before any fatigue sets in)*
- 4×50 catch-up drill, 15s rest
- 4×50 high-elbow catch (fist drill or fingertip-drag), 15s rest

## Bridge — 300m
- 6×50 building 25 easy → 25 moderate, holding today's catch cue as pace rises, 15s rest

## Main set — 1200m
- 4×200 free @ moderate/z2 ("could hold a conversation, but working"), pull buoy on reps 2 and 4, 20s rest
  - Pull-buoy sets are worth treating as technique work, not an arm-strength workout: in masters swimmers, pull-speed correlates far more with pulling efficiency than with raw arm power.
- 4×100 free @ z2–z3, 15s rest
  - **Count strokes per length on every rep and try to hold the same count as the reps go on.** This is the single most evidence-grounded number in the program — the direct marker for whether technique holds up as fatigue builds.

## Cooldown — 200m (as swum — planned 100m)
- Easy free/back, relaxed, technique-focused

**Total: 2500m**

## Metrics to capture

## Notes
- No fins today — fins measurably shorten and flatten the kick and raise energy cost per meter, the opposite of what a steady-state aerobic session is grooving.
- No paddles/kickboard — not needed for this session.
- If CSS hasn't been tested yet (400m + 200m time trial), that's still the one addition that would turn every "z2/z3" above into an actual pace number instead of an effort description.

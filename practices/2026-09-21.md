**Total: 1300m**

## Metrics to capture
- Both time-trial times (400m, 200m) and their 100m splits.
- Stroke count on the **first 50m and last 50m of each time trial** (four counts total: 400-start, 400-end, 200-start, 200-end) — not every length, to avoid competing for attention with pacing during a maximal effort.
- After the session: compute CSS = (400 − 200) ÷ (t400 − t200) in m/s, or CSS pace/100m = (t400 − t200) ÷ 2.

## Notes
- Replaces today's usual Technique + Aerobic Base slot — the framework's tracking table treats the CSS test as "one full session," not something layered onto a normal technique day.
- This is the first CSS baseline for this training log; retest every 6–8 weeks per the framework, and use the resulting pace to set real interval targets in future sessions instead of placeholder paces.
- Stroke count at the start/end of each time trial doubles as a technique-under-fatigue data point (the framework's single most evidence-grounded tracking metric) — a genuinely maximal, sustained effort like this is one of the better occasions to capture it, alongside the regular Day B/C sessions.

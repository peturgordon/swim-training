# 2026-09-12 — Race Distance (Endurance)

**60min / 2500m (planned)**

## Warmup — 400m
- 200m easy free
- 4×50 easy free/back alternating, 10s rest

## Technique — 300m
*(moderate pace, not slow — priming for the main set; continuing this week's high-elbow catch cue)*
- 6×50 high-elbow catch (fingertip-drag) @ moderate pace, 15s rest

## Bridge — 200m
- 4×50 building 25 easy → 25 moderate, holding the catch cue, 15s rest

## Main set — 1400m
- 4×200 free @ z2 ("comfortably working, not race pace"), pull buoy on reps 2 and 4, 20s rest
- **3×200 free @ z2–z3, 20s rest — count strokes per 25m on every length; compare the rep-1 average to the rep-3 average.** Progression from last Saturday's 4×100 version of this set (see [2026-09-05](2026-09-05.md)) — same "hold the count as fatigue builds" test, now on a longer unbroken distance.

## Cooldown — 200m
- Easy free/back, relaxed, technique-focused

**Total: 2500m**

## Metrics to capture
- Stroke count per 25m on the 3×200 tracked set — record rep 1 and rep 3, not just once.
- RPE (1–10) or a 10s pulse count immediately after rep 3 of the tracked set.

## Notes
- Continuing this week's high-elbow catch (fingertip-drag) cue from Monday and Wednesday, at moderate pace here rather than slow-and-isolated — per the framework's Day C card, technique work on the endurance day primes the main set rather than teaching the cue from scratch.
- No fins this session — as on [2026-09-05](2026-09-05.md), fins measurably shorten/flatten the kick and raise energy cost per meter, which cuts against a session built to test how technique holds up under a genuinely unaided, fatiguing effort.
- Pull buoy on 2 of the 4 aerobic-base reps only, not on the tracked 3×200 — the tracked set needs full-stroke kinematics, since it's evaluating exactly the coordination (arms + kick together) that's supposed to be breaking down under fatigue.
- The 3×200 stroke-count set is this week's version of [Training Framework principle 04](../guides/training-framework.html#framework) — described as "the single most evidence-grounded number" in [`research_findings.md`](../research/research_findings.md), the direct proxy for whether technique holds up as fatigue builds. Stepping from 100s to 200s follows the framework's own "~400m broken into 100s or 200s" language as a progression, not a bigger ask than what the framework specifies.
- Pre-pool prehab (side planks + dynamic hip/ankle mobility, ~5min) is recommended per the framework's Day C card — dose isn't validated for this population, treat as prudent general conditioning, not a proven protocol.
- If CSS hasn't been tested yet (400m + 200m time trial), that's still the one addition that would turn every z2/z3 target above into an actual pace number instead of an effort description.

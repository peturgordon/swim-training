## Notes
- **Where today's variety came from:** the last two Mondays ([09-07](2026-09-07.md), [09-14](2026-09-14.md)) ran an identical skeleton — 200 free + 4×50 free/back warmup, catch-up + high-elbow technique, same bridge/aerobic-main shape. Today's kick block is pulled directly from last season's real coaching log ([`research/garpar_sundaefingar_2025-2026.md`](../research/garpar_sundaefingar_2025-2026.md), 8 Oct 2025 session) rather than invented from scratch. The warmup borrows the same session's sculling idea, but toned down — the log's version alternates scull/free for the full 500m (50% sculling), which is too much cold, unassisted feel-work to lead a warmup with; today's version keeps a single 4×50 taste of it (100m of 600m, ~17%) alongside the familiar free/back alternation, rather than either the full import or dropping it entirely.
- **Cue rotation:** switching from high-elbow catch (fingertip-drag) to single-arm drill today. [09-23](2026-09-23.md)'s notes already flagged this Monday as the next natural rotation point (09-21 was a CSS test day, not a technique day, so no new cue was decided that week). Per the framework's own open-questions section, no confirmed research ranks one drill against another for race-pace transfer — the drilling *paradigm* being under-bridged is the identified gap, not any specific drill being wrong — so swapping which classic drill carries the week's cue is a free choice, not something the evidence weighs in on either way.
- **Kick block:** fins stay confined to the Kick and Technique blocks (slow, isolated work) — per the equipment research, fins measurably alter kick mechanics, which is the point during isolated drilling but the reason they're avoided in steady-state main-set swimming. Backstroke kick specifically hasn't appeared in any Monday session yet under this framework; adding it here is the same "other strokes rotated in" idea the Day C card already specifies for Saturdays, applied to Monday for the first time.
- **Aerobic main left unchanged on purpose:** same 4×150 + 1×300 structure and rest as the last two Mondays, even though everything around it changed — preserving this lets the stroke-count metric mean the same thing week to week for that block, the same reasoning [09-14](2026-09-14.md)'s own notes used when it kept the set fixed. The new cue still breaks direct count-for-count comparability against prior weeks (noted above); the structure staying fixed limits that break to "different cue," not "different cue and different set."
- No paddles or kickboard needed this session.
- Pre-pool prehab (banded Y-T-W retractions + thoracic rotations, ~5min) per the framework's Day A card.
- Total distance up to 2700m this week (from 2300m the last two Mondays), mostly from the new Kick block — expect this to run closer to 65min than a strict 60.

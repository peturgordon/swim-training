## Notes
- **Why the change:** the last three Saturdays ([09-05](2026-09-05.md), [09-12](2026-09-12.md), [09-19](2026-09-19.md)) all ran the same shape — a ~400m-broken-into-100s/200s stroke-count set at a z2/z3 HR-effort description. The framework's Day C card names this as one of two alternating options and explicitly offers the other: "Other weeks: 4–6×100–200 @ CSS pace, holding form as the primary metric." Today uses that second option — both to break the repetition and because [09-21](2026-09-21.md)'s CSS baseline test gave a real number to train against for the first time, which [09-23](2026-09-23.md)'s notes already flagged Saturday as the session that would actually use it.
- **CSS pace target:** 1.04 m/s / ~1:36 per 100m / ~3:12–3:15 per 200m, from the [2026-09-21 CSS baseline test](2026-09-21.md) — the first baseline this season; retest in 6–8 weeks per the framework's tracking table (roughly early-to-mid November) before trusting this number much further out than that.
- **Glide trial not continued:** [09-19](2026-09-19.md) tried deliberately lengthening the glide phase as an experiment. Per [`research/research_findings.md`](../research/research_findings.md)'s Pass 4, the glide-heavy/lower-stroke-count model of efficiency isn't supported, and the elite race-pace evidence actually points the other way — stroke *rate*, not a lower count via longer glide, is what tracks speed. Stroke count is still being tracked today (it's the framework's single most evidence-grounded technique-under-fatigue proxy), but a falling count is only a good sign if the split holds too; a falling count with a slower split is the glide-not-grip failure mode, not progress.
- Continuing the high-elbow catch (fingertip-drag) cue from the last two weeks — [09-23](2026-09-23.md)'s notes flagged the next natural rotation point as this coming Monday, not before, so today isn't the day to change it.
- No fins — same reasoning as the last three Saturdays: fins measurably shorten/flatten the kick and raise energy cost per meter, which cuts against a session built to test whether pace and technique hold together unaided.
- 20s rest on the CSS-paced 200s, not longer — short enough to keep this an honest sustained-effort test of the pace, not a fully-recovered interval set; long enough that it isn't degrading into a lactate-tolerance grind that would mask whether CSS pace itself is actually sustainable yet.
- Pre-pool prehab (side planks + dynamic hip/ankle mobility, ~5min) per the framework's Day C card — dose unvalidated for this population, treat as prudent general conditioning, not a proven protocol.
- Total distance stepped up to 3000m this week (from ~2500m the last three Saturdays), per today's specific request — expect this to run closer to 65–70min than a strict 60, a fine occasional adjustment for a distance goal rather than a new default.

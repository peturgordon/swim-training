# 2026-10-03 — Race Distance (Endurance), short-rep version

**~60min / 2500m (planned)**

## Warmup — 600m
- 200m easy free, relaxed
- 6×50 easy, rotating free/back/breast, 15s rest
- 4×25 build (easy → moderate), 15s rest

## Technique — 400m
*(moderate pace, not slow — warming up for the main set; continuing the single-arm cue from [09-28](2026-09-28.md))*
- 4×50 single-arm free drill, alternating which arm leads each length, 15s rest
- 4×50: 25 single-arm / 25 full stroke, carrying the single-arm feel into the full stroke, 15s rest

## Main set — 1200m
*(stroke count held as fatigue builds, broken into 50s instead of 100s/200s — see Notes)*
- 3 × (8×50 free on a 1:05 send-off), plus an extra ~1min rest between blocks
- **Pace: ~49–51s per 50**, a little slower than CSS (~48s per 50). That leaves about 15s rest per rep. If you're getting 20s+ rest, you're going too fast: [Wednesday's](2026-10-01.md) reps ran 40–47s, and today's are meant to be easier.
- Count strokes on the 2nd length of rep 1 and rep 8 in each block.

## Cooldown — 300m
- 200m easy free/back
- 4×25 very easy, any stroke

**Total: 2500m**

## Metrics to capture
- Stroke count on the 2nd length of rep 1 and rep 8 in each main-set block (6 counts in total), with that rep's time next to each.
- RPE (1–10) right after rep 24.

## Notes
- **Why 50s, and why slower than Wednesday:** you asked for short distances like [10-01](2026-10-01.md). That 20×50 was faster than CSS on ~18s rest, which makes it a near-threshold set, so this week has already had one threshold-type session in place of the planned sprint day. Running the same reps at or above CSS again would make the week threshold-heavy. In the polarized-vs-threshold RCT ([research_findings.md](../research/research_findings.md), finding #1), polarized training gave the bigger improvement with less fatigue. So the reps stay similar but the target pace sits just under CSS: steady endurance work, not a repeat of Wednesday.
- **Different from the Day C card:** the card's stroke-count option is "~400m broken into 100s or 200s." This version uses 50s and 3× the volume (1200m), on short rest, so fatigue comes from how many reps there are rather than how long each one is. The start-vs-end stroke count still answers the card's question. A falling count only counts as progress if the time holds too; a lower count with slower reps means you're gliding instead of pulling (Pass 4).
- **Pacing:** on [09-26](2026-09-26.md), the CSS-pace 200s came out ~2.4% too fast. On a fixed send-off, the rest you get each rep tells you right away whether you're on pace.
- **No technique claim for short reps:** the USRPT study also used 20×50, but the claim that short reps protect technique was refuted, so the stroke counts here are something to measure, not an expected result.
- No fins, like every Saturday so far: this session tests unassisted technique under fatigue.
- Pre-pool prehab (side planks + dynamic hip/ankle mobility, ~5min) per the Day C card. The dose isn't validated for this population.

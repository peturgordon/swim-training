# Single-pass research

This folder holds reports written in a single, non-adversarial pass — one model, one draft, no independent verification, no citations to primary sources. They read as polished, confident write-ups, but none of their claims have been checked against the [Pass 1-4 methodology](../research_findings.md) used for the rest of this project's research (search angles → fetch primary sources → extract claims → adversarial verification by 3 independent reviewers → confirmed/refuted synthesis).

**Treat everything here as a source of hypotheses to test, not as evidence.** When a document from this folder gets put through adversarial verification, the result goes into `research_findings.md` as its own numbered pass, and that pass is the citable one — not the original document.

## Contents

- [`stroke-count-efficiency-report.md`](stroke-count-efficiency-report.md) — single-pass, uncited report on stroke count, glide, and freestyle efficiency. Its six central claims were tested via adversarial verification in [Pass 4](../research_findings.md#pass-4--stroke-count-glide-and-efficiency) of `research_findings.md`, which found the report's central thesis (fewer strokes/longer glide = better) largely unsupported, with the evidence pointing the opposite direction for elite freestyle swimmers. Read Pass 4 first; read this file only for the reasoning/mechanisms it proposed, not for its conclusions.
